# Arah desain CBT GAEKS

- Palet hijau pabean gelap dipakai untuk identitas institusional dan rasa terpercaya; sian hanya menandai aksi, fokus, dan progres.
- Inter dipakai karena angka, label singkat, dan teks soal tetap mudah dipindai pada layar ujian yang padat.
- Pemain ujian memusatkan soal dan menaruh navigator nomor sebagai alat bantu ringkas, bukan sebagai panel dekoratif.
- Sudut sedang, bayangan tipis, dan jarak konsisten menjaga hierarki tanpa memberi kesan aplikasi promosi.
- Gerak dibatasi pada status simpan, perpindahan soal, dan dialog konfirmasi agar tidak mengganggu konsentrasi peserta.
