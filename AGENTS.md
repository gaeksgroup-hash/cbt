## antislop
For UI, copy, people, mobile layout, or code comments work, use the installed antislop skills:
- Core: `antislop:antislop`
- UI / visual: `antislop:antislop-ui`
- People and accessibility: `antislop:antislop-human`
- Mobile / responsive: `antislop:antislop-layoutmobile`

Resolve the antislop usage mode before UI work. An explicit session choice overrides a global preference. In editing mode, announce the resolved mode before the first edit. Run the core Delivery Gate before delivering UI work.
